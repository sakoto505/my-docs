# API 参考

以下接口仅用于文档展示，**不提供真实服务**。本页主要演示如何在 MkDocs 中书写接口说明、
参数表与返回示例。

## 通用说明

| 项目 | 说明 |
| --- | --- |
| 基础路径 | `/api` |
| 数据格式 | `application/json` |
| 字符编码 | UTF-8 |
| 鉴权 | 示例中省略 |

## 查询文档列表

- 请求方法：`GET`
- 请求路径：`/api/docs`
- 功能：返回文档条目列表。

### 查询参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `page` | integer | 否 | 页码，默认 1 |
| `size` | integer | 否 | 每页数量，默认 20，最大 100 |

### 请求示例

```bash
curl -X GET "https://example.com/api/docs?page=1&size=20" \
     -H "Accept: application/json"
```

### 返回示例

```json
{
  "items": [
    {"id": 1, "title": "使用指南"}
  ]
}
```

### 返回字段说明

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `items` | array | 文档条目数组 |
| `items[].id` | integer | 文档唯一标识 |
| `items[].title` | string | 文档标题 |

## 获取单个文档

- 请求方法：`GET`
- 请求路径：`/api/docs/{id}`

### 路径参数

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| `id` | integer | 文档唯一标识 |

### 返回示例

```json
{
  "id": 1,
  "title": "使用指南",
  "updated_at": "2026-11-13T10:00:00+08:00"
}
```

## 错误码约定

| 状态码 | 含义 | 典型场景 |
| --- | --- | --- |
| 200 | 成功 | 正常返回 |
| 400 | 请求参数错误 | `size` 超过上限 |
| 404 | 资源不存在 | `id` 不存在 |
| 500 | 服务端错误 | 内部异常 |

## 写接口文档的一点体会

写接口文档时，**参数表和返回示例比大段文字更有用**。读者通常只关心三件事：怎么调、传什么、
拿到什么。因此我把每一节都整理成"路径 → 参数表 → 示例 → 字段说明"的固定顺序，方便扫读。

另外，示例里的 JSON 一定要能通过校验——读者会直接复制粘贴去试，格式错一个逗号就会浪费他
半小时。这也是我偏好用代码块而不是纯文本描述接口的原因。
